# 🎮 2D Platformer Game (Python + Pygame)

A simple yet fun 2D platformer built with **Python** and **Pygame**.

---

## 🧠 Features
- Jump and move using arrow keys + spacebar  
- Gravity and platform collisions  
- Simple level design  

---

## 🧰 Requirements
- Python 3.x  
- Pygame

Install dependencies:
```bash
pip install pygame

python3 platformer_game.py
